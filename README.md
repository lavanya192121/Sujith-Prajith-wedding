# Sujith Prajith Wedding

Build a luxury traditional Indian wedding invitation website for Sujith & Prajith inspired by the attached Radha-Krishna artwork. Include the interactive landing cover with clickable initials 'S ♡ P', cinematic reveal of the couple's names and wedding date (18 January 2027), real-time countdown timer, event details for the wedding and reception in Kottayam, photo gallery with lightbox preview, location map and directions, RSVP with WhatsApp and phone call buttons, and a closing thank-you section. Style throughout with the sage green, ivory, and muted gold palette, glassmorphism cards, lotus, peacock feather, and traditional Indian motifs, fully responsive and mobile-optimized.
